# In Case of Emergency - Plain English Guide

This document is written for family, a solicitor, an executor, or anyone acting under power of attorney. It does not assume any technical knowledge.

Last updated: 2026-08-02

## What Is This, And Am I At Financial Risk?

This document explains an automated computer system that Mike built to help him monitor financial markets. It is NOT an automated trading robot. It only sends text messages and emails with information. It has never placed a single trade automatically, and cannot do so. All actual buying and selling decisions were always made by Mike personally, by hand, through his brokers own app.

As of 2 August 2026, Mike has NO open trading positions. This means there is currently no money actively at risk in the market because of this system.

This system does have a small number of monthly subscription costs attached to it, which should be cancelled if Mike is no longer able to manage them himself. See later sections for details.
